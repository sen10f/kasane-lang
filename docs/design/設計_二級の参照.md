# 設計: 参照は二級の値 (中間型)

決定 (利用者、2026-11-16): 借用のモデルを「中間型」にする。`批判的レビュー round4` の Q2 の答え。Edition 1 の凍結の前に入れる、互換性の無い変更。
Rust 型 (構造体に `&'a T`) をやめ、Hylo 型 (参照は引数と局所だけ) へ寄せる。ただし `Option<&T>` / `Result<&T, E>` / タプルは局所では許す。
目的は検査の縮小 (欄・容れ物・チャネルの経路にある借用の流れを検査しなくてよくなる) と、`type t.View['a]` のような型を LLM が書いて通らなくなる穴を最初から塞ぐこと。

## 1. 規則 (正確な定義)

### 1.1 用語: 参照を運ぶ型 (RC)
次のいずれかを「参照を運ぶ型」とする。
- `&T` / `&mut T` (ライフタイムが `'static` でないもの。省略も含む)。`&'static T` は借用ではない (領域を持たない) ので RC ではない。
- ライフタイム引数を持つ名前付きの型の使用: 標準の `core.slice.Iter<'a, T>`・`core.str.Chars<'a>`・`core.str.Split<'a, 'b>`・`alloc.collections.HashMapIter<'a, K, V>`・`std.sync.MutexGuard<'a, T>`。利用者の型は (1.2 により) ライフタイム引数を持てないので、これらだけ。
- RC を含む `Option` / `Result` / タプル / 配列 `[T; N]` / スライス `[T]` / `&` / `&mut` (参照の参照を含む)。
- RC を型引数に持つ総称型 (1.3 で拒まれない範囲。`core.iter.Map<core.slice.Iter<'a, T>, F, ..>` のようなイテレータの連鎖は、それ自体が RC)。
- 参照を取り込んだ閉包 (`capture [&x]`・`[&mut x]`、または RC の値を `move` で取り込むもの)。
- `dyn Tr + 'a` (`'a` が `'static` 以外)。`&dyn Tr + 'a` は参照なので元から RC。

### 1.2 禁じる位置 (1): 利用者の型の宣言
`type` の欄の型・`enum` の変種の中身の型が RC のとき、およびヘッダの型パラメータ列にライフタイム (`type t.View['a]`) を宣言したとき、E3060。
- `&'static str` の欄は許す (領域を持たず、文字列表・名前表に実用上要る。`selfhost/driver/src/ksnc/clang.ksnl` の `Vec<&'static str>` も同じ)。
- `Option<&T>` を欄に置くのも E3060 (RC を含むため)。
- 標準ライブラリの `.sig` に書いた組み込みの型 (`Iter` `Chars` `Split` `HashMapIter` `MutexGuard`) の宣言は対象外 (処理系が持つ型で、利用者が複製できない)。`.ksnl` で書いた標準ライブラリの型は対象 (`core.fmt.Formatter` と `std.json.Value` は 4 段で規則に合わせる)。
- 欄の参照のライフタイム省略 (E3020) は、この規則のもとで意味が無くなる (参照の欄は全部 E3060)。E3020 は残す (E3060 の前の段の診断として)。

### 1.3 禁じる位置 (2): 容れ物・共有・送受信の型引数
次の標準の型 (と、利用者の総称の `type` / `enum`) の型引数に RC を入れると E3060。位置は、ヘッダの引数・戻り値、`let` の型注釈、式中の型引数 (`Vec::<&T>`)、推論で決まった型のすべて。
- `alloc.vec.Vec`・`alloc.collections.*` (`HashMap` `BtreeMap` ほか)・`alloc.boxed.Box`・`alloc.rc.*`・`alloc.raw.Buf`・`std.sync.*` (`Arc` `Mutex` `RwLock` `Sender` `Receiver` ほか)・`std.thread.JoinHandle`・`std.task.Task`。
- 利用者の総称の型 (`t.W<&u32>`: 欄が型パラメータなので、実質は欄に参照を置くことになる)。
- 許す総称: `Option` `Result` (局所の値としてだけ。`Option<&T>` を欄に置けないのは 1.2 による)・タプル・配列・スライス・イテレータ部品 (`core.iter.*`、`Iter` など。借用を運ぶのが目的の型)。
- 総称の関数の型引数 (`t.id(&x)`、`f::<&u32>(..)`) と、トレイト境界・`Fn<(&T,), ..>` の引数は対象外 (値を保存する位置ではない)。
- 整理: 容れ物の型引数に `&T` を入れる必要は、要素の所有する値・添字・`Option<&T>` を返す `get` で代用できる。仕様 4.1 の `fn app.util.keep['a](v: &mut Vec<&'a T>, x: &'a T)` (入力どうしを結ぶライフタイム) の例は、この規則で書けなくなるので 4.1 から外す (E3021 の説明は「出力にも現れる」場合だけを残す)。

### 1.4 閉包
- 参照を取り込んだ閉包 (RC) を、利用者の型の欄・容れ物・チャネルに入れること、`spawn` すること、関数の外へ返すことを禁じる。
- 関数の外へ返す: 返せる閉包の型は `fn(..)` (環境なし) か `Box<dyn Fn + 'static>` だけで、どちらも参照を取り込めない。つまり構造上すでに書けない (E2037・E3010 が拒む)。
- 欄・容れ物: 欄は 1.2、容れ物は 1.3 に入る (閉包の型が RC のとき)。実装は、閉包の式の `capture` を見て、その値を容れ物へ渡す形 (`push` ほか) とチャネルの `send`・`spawn` への引数・欄の初期化を E3060 にする。型で追えない (決まらない) 所は拒む側 (fail-closed)。
- 局所の呼び出し (`let f = fn(..) capture [&x] {..}` を呼ぶ、高階関数の引数に渡す) は従来どおり許す。

### 1.5 許すもの (確認)
引数で参照を受ける。参照を戻り値で返す (省略の規則か `['a]` で引数に結ぶ)。局所に参照・`Option<&T>`・`Result<&T, E>`・タプルを持つ。総称の関数の型引数に参照を入れる。借用検査 (4.1) は局所と引数・戻り値の間の流れだけを見ればよくなる (欄・容れ物・チャネルを経由する流れが消える)。

## 2. 診断コード
- **E3060** (参照を運ぶ型を、型の欄・容れ物・チャネルに入れた。空き番号を `ksn explain` の一覧と `src` の全文検索で確かめた。E3050 の次)。メッセージは 3 種類: 型の宣言に参照 / ライフタイム引数、容れ物の型引数に参照、参照を取り込んだ閉包を保存。直し方は 「位置の添字を持つ・元のデータは引数で渡す・所有する値 (`String` `Vec<T>`) にする」 を示す。
- 既存の E3010 (流れの検査) は欄・容れ物を通る流れの形が減るが消さない (保守側。`unsound/` の拒否はそのまま通る場合がある)。

## 4. 実装の置き場
- `stage0/src/refs_check.rs` (新規): 型の宣言と型の使用 (ヘッダ・`let` の注釈・式中の型引数) を `Def` / 構文木から見る。決まらない型は拒む側。推論で決まった型 (`let v = Vec::new(); v.push(&x)`) は、`types.rs` の推論の終わり (`report_undetermined`) から 1 か所呼ぶ関数で見る。
- 既存の検査の流れ (`check.rs`) から `refs_check::check(..)` を 1 か所で呼ぶ。
