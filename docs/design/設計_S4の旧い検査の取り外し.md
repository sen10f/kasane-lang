## 3. 削除の順序 (各段は `shadow_diff.py --full` で台帳に新しい差が出ないこと、`rephrase` で hole が増えないこと、`cargo test --release` を確かめる)

1. 旧の効果検査 E4001/E4002 + 実体化 (約 250 行)。独立していて小さい。`effects_*` が覆う。
2. E1122 `check_impl_method_sigs` (約 150 行)。
3. E3031 可変性・E2030 `check_bounds`・E2021/E2052 網羅性・E2042 捨てた値 (約 600 行)。S4D の規則がそれぞれ 1 対 1。
4. 引数の型・参照段数の E2023 呼び出し (約 300 行)。型パラメータの個数の E2023 は残す。
5. 移動・線形 E3002/E3003/E3006 (約 700 行)。`with_check.rs` の E3040 は `moves.rs` で全件を覆うか確かめてから同時に。
6. `borrowck.rs` (約 4,300 行)。最大で最も危ない。まず `check_closure_*` と `check_lifetime_store` / `check_return_flow` (寿命、約 1,200 行) を `lifetimes.rs`/`captures.rs` で外し、次に `analyze` と `Low::lower_*` (競合、約 3,000 行) を `borrows.rs` で外す。E3010 の残り約 10 行 (S4E で TAST 化するまでは旧に残る) が消す前の条件。
7. 最後に `KSN_CHECKER` の `old` / `shadow` と `select` の分岐を消し、`shadow_diff.py` を新検査の回帰用に縮める。

前提: 各段で旧パスを消すと、その診断の出どころが TAST だけになるので、`E3060` が覆う二次診断の台帳 (E3010 約 20 行) は旧の E3010 が消えても期待が合うか個別に見る。
