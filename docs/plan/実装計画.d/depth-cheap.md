# depth-cheap: 再帰の輪で深さを隠れた引数にする

- 呼び出しの輪 (自己再帰・相互再帰。純粋域・wasm 公開・`ksn.` は除く) に入る関数 `f` は 2 本出す。`k.f.d(i64 %depth, args)` (本体。入口の検査と `%depth+1` の計算はここ。大域 `@ksn.depth` は読み書きしない) と、外から入る入口 `k.f` (大域の深さを読んで `.d` を呼び、戻ったら書き戻す)。
- 輪の中の呼び出しは `.d` に `%depth1` を渡す (レジスタ)。輪の外の Kasane 関数・extern・`Proc` を呼ぶ直前だけ `store %depth1, @ksn.depth` で大域を合わせる。深さの超過の点 (深さ ≥ dmax、スタックの底) は元と同じ。
- 測定 (release、手元): fib(38) 0.575 → 0.31 s (Rust -O 0.29 s)、相互再帰+木再帰 3.9 → 2.3 s。
