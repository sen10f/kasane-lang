# fmt/fold-long-calls (Mythos-scale2 §4 B1, P0-a)

100 文字を超える行を括り出せないとき、`ksn fmt` が一番外の呼び出しを「引数 1 つ 1 行」(`f(` / 引数 `,` / `)`) に畳む (fmt_hoist.rs の `fold_line`/`fold_expr`)。
- 対象: 文 (`let`/代入/`return`/式)、`if [!]呼び出し {`、`match 呼び出し {`、腕 `P => 式`。末尾は `?` と引数なしメソッド (`.is_err()`) だけ。受け手は 1 行に残す。入らない引数は入れ子で畳む。
- 腕を `P => {` に開くのは、開いた先で `let` に括り出せるときだけ (`open_arm`。本体が 1 文のブロックの腕は fmt が 1 行に戻すため、`let` が無いと不動点にならない)。
- E0055 の文面に、引数 1 つ 1 行と腕の開き方を足した。
- 残る限界: 引数の中の構造体リテラル `{`・閉包・文字列を含む行・比較演算子つきの条件の呼び出し。
