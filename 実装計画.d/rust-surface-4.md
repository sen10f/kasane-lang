### 2.10?? `ksn fix` の Rust 風の表面の書き換え (4 回目)

- 足した書き換え (`surface_fix.rs`): 見出しの末尾の `:` (`trait N[..]:`)、`type N: f: T end N` (コロン + 1 行)、`' static` → `'static`、`impl` の中のメソッドの短い `end <名前>` と、重ねた閉じ (`end Y` の後の `end impl ..`) の除去、空の `impl T for Y` に付いた `end T for Y` の除去、欄の省略形 `T { x, y }` → `T { x: x, y: y }` (E0061。`if`/`match` などの行は触らない)。
- 直さない形 (文面だけでは型・捕捉が決まらない): Rust の閉包 `|x| expr` / `|x: T| { .. }` (`position(|n| ..)`、`map_err(|_| ..)`、`and_then(|p| ..)` など、引数・戻り値の型が文面にない。`fn(x: T) -> R capture [..]` へは推測なしには書けない)、`a | b =>` の or パターン (腕の本体を複製する必要)、`b'0'` のバイトリテラル、100 字超の行 (E0055)、`&s[..w]`。
- 計測 (api_bench の 2 ディレクトリ 34 本、最初の診断が E00xx の本数): 23 → 19 (残りは上の形と E0020 / E0055 の整形の失敗)。
