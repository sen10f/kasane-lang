# 長い行の括り出し (`ksn fmt`、2026-11-23)

`stage0/src/fmt_hoist.rs`。100 文字を超える行 (E0055) を `let` への括り出しで縮める。折り返しは禁止のまま。
- 呼び出し `f(a, b, ..)` の先頭からの引数 (`hoist_call`)。値だけを作る式のみ。`&`・`|`・`{}`・`::`・`None`・`.new()` 系・一時値を借りるメソッドは括り出さない。名前は `<受け手>_<メソッド>`。
- `if a || b ..` / `let x = a && b ..` の左の連なり (`hoist_cond`)。同じ演算子だけ。名前は `<x>_a`・`cond`。
- 数 (Copy) を返すメソッド (`wrapping_*` ほか) の連鎖の前半 (`hoist_chain`)。名前は `<x>_a`, `_b`。
- 名前は snake_case (`_2` は不可) で、関数内の既存の名前と衝突したら `_b` `_c`。ファイルに 1 行でも直せない行があれば、ファイル全体を触らず E0055 のまま (all-or-nothing)。
- 括り出したら整形をもう一度かけて不動点にする。`cli.rs` の fmt は、読み込みが E0055 などで失敗するファイルでもこの経路で整形する。
- 未対応: 構造体リテラルの欄、`match f(..) {` の見出し、`else if`、`while`、文字列を含む行 (元から E0055 の対象外)。
- 測定: mythos-scale の実験の答案 (67 パッケージ) の E0055 の残る 15 本は、どれも別の構文の誤りも持ち、E0055 だけの答案は無かった。fmt で E0055 が消えた答案は 0 (構造体リテラル・`else if`・配列リテラルが主)。
